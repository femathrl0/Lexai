# 0013 — Portões decididos sem reunião

Data: 27/11/2026 · Registro: Felipe (responsável pelos portões nas issues #7, #14, #21, #28, #35, #42, #49).

**Contexto.** O manual prevê uma reunião de Demo e portão ao fim de cada semana. O grupo decidiu não fazer essas reuniões.

**Decisão.** O responsável pelos portões registra a decisão de cada semana no arquivo do portão (`0005`, `0007`–`0011`), com a evidência na própria página, e fecha a issue do portão quando a decisão é *aprovado* ou *aprovado com desvio*. Portão reprovado ou não aprovado fica aberto com o que falta. Quem discordar reabre a issue com o motivo; a revisão vira uma nova decisão.

**Alternativa descartada.** Deixar os portões em aberto até uma reunião: a semana seguinte do roteiro não teria critério registrado.
